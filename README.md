#  Blinkit Sales & Performance Dashboard  
A Complete End-to-End Power BI Analysis Project

This repository contains an interactive Power BI dashboard built using a real-world style dataset inspired by Blinkit — India’s rapid delivery platform.  
The goal of this project is to analyze **sales trends, outlet performance, product categories, fat content, item visibility, and customer ratings** to drive business insights.

---

##  Dashboard Overview

This Power BI dashboard helps answer important business questions such as:

- What are the total sales and how do they vary across outlets?
- Which product categories generate the highest revenue?
- How does fat content (Low Fat vs Regular) impact sales?
- What is the distribution of sales across outlet sizes?
- Which outlet tier performs best?
- What are the average ratings and number of items sold?
- How do items differ in visibility and contribution to revenue?

---

## Key Features in the Dashboard

### **KPIs**
- Total Sales  
- Average Sales  
- Total Number of Items  
- Average Rating  

###  **Visuals Included**
- Donut chart for Fat Content  
- Bar charts for Item Types  
- Pie chart for Outlet Size  
- Ranking chart for Outlet Location (Tier 1 / 2 / 3)  
- Table analysis by outlet type  
- Filters for:
  - Outlet Location  
  - Outlet Size  
  - Item Type

##  Dataset

This project uses a structured dataset designed specifically for sales analytics.  
The dataset includes:

- Item Fat Content  
- Item Type  
- Item Visibility  
- Item Price  
- Outlet Size  
- Outlet Location Tier  
- Outlet Establishment Year  
- Item Rating  
- Total Sales  

>  **Note:** Dataset used here is for learning and portfolio purposes only.  
> It is uniquely prepared for this dashboard and does not represent actual Blinkit data.
